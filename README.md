# Bound

A book club app for iOS. Track what you're reading on real-looking shelves, share spoiler-safe notes with your club, and plan the monthly meetup in one place.

Built with SwiftUI + SwiftData.

## Features (planned)
- Shelves: To read, Reading now, Finished, plus custom shelves and favourites
- Club notes: ratings and reviews, folded until you've caught up to that page
- Meetups: date, place, RSVP, and voting on next month's pick
- Club ledger: every book the club has read, with ratings
- Paper-tear screen transitions

## Status
Early development. Local data only for now.
